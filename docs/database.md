# پایگاه داده
Prisma + PostgreSQL. مدل‌ها در `prisma/schema.prisma`. تغییرات فقط با Migration (`npx prisma migrate dev` در توسعه، `migrate deploy` در تولید). زمان‌ها UTC؛ نمایش در Asia/Tehran. جدول‌های صف را pg-boss در طرح `pgboss` مدیریت می‌کند. جدول `ProcessingJob` فعلاً استفاده نمی‌شود (در صورت نیاز به ثبت نتیجه کارها).
