# امنیت
- ورودی‌ها با zod اعتبارسنجی می‌شوند؛ Prisma پارامتری است (بدون SQL خام کاربر).
- SSRF: `assertSafeUrl` روی هر URL و هر redirect؛ IPهای داخلی و متادیتای ابری مسدود.
- مدیر: توکن موقت؛ **باید** قبل از استقرار با Identity (کاربر، نقش، نشست، CSRF) جایگزین شود.
- متن منابع داده غیرقابل اعتماد است؛ JSON-LD با escape خروجی می‌شود. اسرار فقط در `.env` (در git نیست).
