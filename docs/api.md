# API
پایه: `/api/v1`. مستند زنده: `/api/docs`. عمومی: `GET /health`, `/categories`, `/articles`, `/articles/:id`. مدیریت (Bearer موقت): `/admin/dashboard`, `/admin/sources` (GET/POST/PATCH), `/admin/sources/:id/run`, `/admin/audit`. قالب خطا: `{ error: { code, message, details? } }`. محدودیت نرخ: ۱۲۰ درخواست در دقیقه.
